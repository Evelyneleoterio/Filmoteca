# Filmoteca, sua locadora virtual de filmes antigos! 🍿📼

### O que é a Filmoteca?

Este projeto foi feito para o 4º seminário interdisciplinar do curso de Análise e Desenvolvimento de Sistemas.

O objetivo deste projeto é ser a prática dos estudos em desenvolvimento web, contemplando todas as etapas de construção de um sistema, desde o design da interface até a implementação da lógica de backend, tornando-o funcional e interativo para o usuário. Com a temática voltada para o aluguel de filmes em um ambiente virtual inspirado nas clássicas locadoras das décadas de 1980 e 1990, traz como funcionalidades o cadastro, atualização e exclusão de informações do usuário.

### Já pegou sua pipoca? **É hora da nostalgia!** 🍿

Para ver esta aplicação em sua máquina, é necessário de seguir os passos abaixo:

1. Faça download deste repositório;
2. Em seu editor de código favorito, abra o repositório na pasta correspondente ao projeto.
3. Lembrando que você deve ter o Python e pip instalado em sua máquina.
4. No prompt de comando/terminal, digite:

`venv\Scripts\activate` // Cria um ambiente virtual em sua máquina

5. Instale as bibliotecas dentro do arquivo requirements.txt para rodar o projeto

`Pip install -r requirements.txt`

6. Após a instalação das bibliotecas, digite o comando abaixo para rodar a aplicação:

`python app.py run`

7. Segure a tecla ctrl + botão esquerdo do mouse no endereço que começa com _http://_ aparecer no terminal.

8. Divirta-se!
